# 氩 Franck–Hertz 激发能量分析

本文源码对应论文《氩弗兰克–赫兹实验中有效激发能量分布的建模》。

本源码配套的教学案例，将实测集电极电流、单一有效激发能量、连续有效激发能量分布及四个分立的 Ar 4s 光谱参考能量连接起来。平滑分布描述模型中的有效激发贡献，不意味着原子参考能级成为连续谱。

[English documentation](README.md)

## 启动并选择模式

Windows 下打开 `start.cmd`。它优先使用已存在的 `.venv`，否则使用当前环境中的 Python。也可以在仓库中运行 `python run.py`。菜单只需选择数字，不需要填写分析参数。

| 模式 | 内容 | 依赖 |
| --- | --- | --- |
| 1 | 从保存参数重算 H1 和六个连续分布阶段，输出拟合电流、分布统计量和复算核对记录；不运行优化器。 | 下述 Python 科学计算包 |
| 2 | 从保存的源表重绘图 1、2、3 和 S1，保留原有 R/ggplot2 绘图设置。 | R 及下述四个 R 包 |
| 3 | 从保存的 H1 起始参数接续既有拟合，包括分布初始化和参数交替更新。 | 下述 Python 科学计算包 |
| 0 | 退出。 | 仅 Python 标准库 |

模式 3 的耗时可能明显长于参数复算。它接续已有起点和优化顺序，并非新的独立实验，也不是从任意初值重新开始。优化记录保存在 `refit.log`。

每次选择均写入新的 `outputs/<时间>_<模式>/` 目录，不覆盖输入和保存的参考结果。程序按源码位置解析路径，仓库可以移动。不自动安装依赖或下载数据，不要求 CUDA。数值计算使用单线程 CPU 和 float64，并保留原始数据转换约定。

## 文件与输出

- `data/`：原始测量工作簿，以及数据概览使用的 805 点 CSV。拟合沿用阻滞电压 0、4、6、8 V 的 644 个测量点。
- `reference/starting_h1/`：模式 3 的保存起点；`reference/stages/`：模式 1 使用的 H1 与连续分布各阶段拟合结果。
- `reference/tables/`：模式 2 使用的论文源表。四个光谱能量在拟合之后用于对照。
- `src/fh_argon/`：当前电流响应模型、复现流程及 `_compat/` 中保留的实现依赖。
- `figures/`：R 绘图源码。模式 2 在自身输出目录导出 PDF、SVG、PNG 和 TIFF，包括独立的图 1a 示意图。

模式 1 输出 `replayed_currents.csv`、`distribution_summaries.csv` 和 `replay_checks.json`。模式 3 将各阶段结果保存到 `stages/`。

报告的峰位取自原有 0.025 eV 计算网格。图 3 的更细绘图网格用于平滑计算既有样条，不重新定义报告峰位。阶段表保留初始化引入的有限宽度，以及之后分布和电流高斯展宽的变化。

## 现有环境与依赖

Python 数值模式需要 `numpy`、`pandas`、`scipy`、`torch` 和 `openpyxl`。`requirements.txt` 记录本地复算所用版本，该次核查使用 Python 3.13.7。PyTorch 不限定 CUDA 构建后缀，因为计算使用 CPU。

绘图需要 `PATH` 中可访问的 `Rscript`，或者通过 `R_HOME` 指定的现有 R 安装，以及 `ggplot2`、`patchwork`、`svglite`、`ragg` 四个包。R 用户库必须对实际启动的 `Rscript` 进程可见，并需支持 Cairo PDF 导出。图件保留论文的 Arial 字体设置，字体可用性由现有系统决定。

菜单仅检查所选模式需要的依赖。缺少依赖时给出说明，不启动安装。需要调整环境之前，应先复用兼容的现有环境。

## 由 AI agent 协助复现

1. 阅读本说明，寻找已经存在的 Python 环境。核对 Python 版本及上述五个包与 `requirements.txt` 的对应关系，不自动创建或替换环境。
2. 激活该环境后运行 `python run.py`；若仓库已有 `.venv`，也可通过 `start.cmd` 使用它。无需将个人机器路径写入源码。
3. 绘图前检查 `Rscript` 是否可用，以及四个 R 包是否对同一进程可见。可通过当前会话环境暴露已有用户库，不将个人库路径写入仓库。
4. 先选择模式 1 查看电流复算与分布统计量，再使用模式 2 绘图。只有明确需要再次优化时才运行模式 3，并保留新输出和原参考结果。
5. 报告实际执行的模式及相对输出目录。参数复算、重绘和拟合是不同活动，均不增加独立测量或置信区间。
