# Historical four-energy comparison

The saved tables in `reference/optional_h4s/` describe a five-curve periodic-response model with leave-one-retarding-curve-out fits. H4s fixes the separations of four Ar 4s reference energies and fits their common shift and response weights.

For a classroom exercise, identify the prescribed separations, fitted shift, and weights. Calculate successive-collision combinations of the four energies, then compare that representation with the main continuous distribution.

The historical fit records are supplied as tables. The current menu runs the convolution workflow; its free-discrete comparisons are described in [discrete diagnostics](discrete_diagnostics.md).
